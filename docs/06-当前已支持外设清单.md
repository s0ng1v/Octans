## 五、全品牌通用兜底通道（零配置自动识别）

1. **标准 HID 电池协议**（`core/hid_parse.c`）：所有遵循 USB-IF 标准 HID 报告描述符（UsagePage `0x0006` / `0x000D` / `0x0085`）的微软 Surface 键鼠、触控笔、部分蓝牙键鼠和公模无线设备，自动扫描并换算 `0..100%`。
2. **Windows 系统蓝牙属性**（`core/bluetooth.c`）：所有向 Windows 上报 HFP / BLE 电池电量的蓝牙耳机、蓝牙鼠标、蓝牙键盘、蓝牙手柄自动通吃。
